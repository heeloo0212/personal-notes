## 文档结构说明

- **深度版**：单题深挖，适合反复精读，应对面试官逐层追问。
- **补充版**：广度覆盖，每题详解，建立完整知识网，适合系统过一遍。

## 复习路线

- **第一轮（建框架）**：先读「补充版」全过一遍，标 ⭐ 高频高难。
- **第二轮（深原理）**：读「深度版」，重点「核心原理 + 追问」自问自答。
- **第三轮（项目演练）**：把每题「项目映射」串成 STAR 故事：
  - Java：IOT 平台、产能统计、ELK、风控 Java 侧
  - AI：风控、爬虫、图谱、IOT 微调、开放追问
- **第四轮（模拟）**：录音回放，控语速结构（结论先行→分点→举例）。
