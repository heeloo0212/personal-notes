# 面试准备索引

> 求职方向：AI 应用开发工程师 | 6 年经验 | Java + AI 复合背景

## 题库（深度版）

- [[Java面试题]] — 41 题，覆盖 JUC/AQS/JVM/GC/类加载/Spring 全家桶/MyBatis-Plus/Redis/RabbitMQ/MySQL/消息/工程实战，每题含原理+源码+追问+项目映射
- [[AI应用面试题]] — 44 题，覆盖 Transformer/vLLM/Agent/MCP/LangChain/RAG/微调/蒸馏/CV/Docker/项目实战，每题含原理+细节+追问+代码

## 每题结构

- **核心原理**：能讲清「为什么」
- **关键细节/源码**：能讲清「怎么实现」
- **常见追问**：能应对面试官深挖
- **代码示例/项目映射**：能落到你的简历项目

## 复习路线

- **第一轮（建立框架）**：通读两份文档，用 ⭐ 标注高频高难（⭐⭐⭐ 必背）
- **第二轮（深化原理）**：只看「核心原理 + 追问」，自问自答，能复述
- **第三轮（项目演练）**：把每题「项目映射」串成 STAR 故事
  - Java 35–41 题（IOT 平台、产能统计、ELK、风控 Java 侧）
  - AI 31–44 题（风控、爬虫、图谱、IOT 微调、开放追问）
- **第四轮（模拟）**：录音回放，控语速和结构（结论先行→分点→举例）
